\# ShopSphere



Big Data Analytics project for e-commerce order analytics using Hadoop MapReduce, Hive and Pig.



\## Team 1



\### Problems

1\. Category-wise revenue and order count

2\. City-wise revenue analysis

3\. Average order value by membership tier

4\. Top 5 customers by total spend

5\. City-wise order percentage and membership-tier analysis

6\. Hive and Pig implementation of Problem 3



\## Technologies

\- Hadoop

\- HDFS

\- MapReduce

\- YARN

\- Hive

\- Pig

\- Java
